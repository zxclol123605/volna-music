# Музыкальный плеер «Волна» 🌊

Стильный, современный Android-музыкальный плеер, вдохновленный Яндекс.Музыкой, с оригинальным дизайном и полной поддержкой стриминга, фонового воспроизведения и караоке-текстов песен.

---

## 🚀 Возможности приложения

- **«Моя волна»**: Персональный бесконечный поток музыки в одно касание.
- **Топ-чарт и подборки**: Интеграция с каталогом треков и превью.
- **Караоке-тексты (LRC)**: Поддержка синхронизированных текстов песен через LRCLib с собственным парсером формата LRC без сторонних библиотек.
- **Фоновое воспроизведение**: Media3 ExoPlayer + `PlaybackService` (`MediaSessionService`) с управлением через системное уведомление, AudioFocus и WakeLock.
- **Мини-плеер и полноэкранный плеер**: Размытие фона (blur), marquee для длинных названий, перемотка и кнопки управления.
- **Умный поиск**: Быстрый поиск с debounce 300 мс и историей поисковых запросов в локальной базе данных Room.
- **Коллекция (Моя музыка)**:
  - Любимые треки (лайки)
  - Плейлисты с сортировкой:
    - *Недавно добавленные*
    - *По алфавиту (А-Я)*
    - *По количеству треков*
  - Офлайн-раздел
- **Профиль и эквалайзер**:
  - 5-полосный эквалайзер
  - Выбор темы оформления (Тёмная / Светлая / Системная)
  - Настройка качества звука
  - Очистка кеша

## 🛠 Технологический стек

- **Язык**: Kotlin
- **UI**: Jetpack Compose + Material 3 Design
- **Архитектура**: MVVM + Clean Architecture
- **Аудио-движок**: AndroidX Media3 (ExoPlayer + MediaSession)
- **База данных**: Room (SQLite)
- **Сетевой стек**: Retrofit 2 + OkHttp 4 + Moshi
- **Загрузка изображений**: Coil Compose
- **Асинхронность**: Kotlin Coroutines & StateFlow

## 📦 Сборка через GitHub Actions

В репозитории настроен автоматический CI/CD workflow `.github/workflows/build.yml`. При каждом `push` в ветку `main` или запуске вручную (`workflow_dispatch`), GitHub Actions компилирует проект и прикрепляет готовый APK в разделе **Actions** -> **Artifacts** (`Volna-debug-apk`).

## 💻 Сборка в Android Studio

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   ```
2. Откройте проект в **Android Studio** (Hedgehog, Iguana, Ladybug или новее).
3. Дождитесь завершения Gradle Sync.
4. Запустите на эмуляторе или физическом устройстве (Run 'app').
